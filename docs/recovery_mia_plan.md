## Membership audit and controlled extension

Keep auxiliary buckets from the old protocol. Buckets0/1 and2/3 fit two attack-training shadows;4/5 provide development validation;6 remains independent original nonmember threshold calibration. Previously unused bucket7 is split by groups into a fresh final shadow member/nonmember pair. No final groups participate in classifier fit, calibration or hyperparameter selection. Existing training-fitted preprocessing is held fixed: this evaluates weight membership conditional on the transformer, not preprocessing deletion.

Train four shadows for15 FL rounds with the same architecture/lr and class-balanced five clients. Set batch size once from auxiliary member count and target mean per-client steps per round, minimum8. This approximates target update count without duplicating target data; smaller batch, dataset size and IID clients remain transfer limitations. No search over attack/shadow hyperparameters or score reversal. Save all memberships and realized budgets.

These validate measurement/power in a constructed setting, not target privacy.

## Evidence-driven amendment before improved shadow training

The encoded-vector preflight found one shared encoded signature between old auxiliary buckets2 and5. Stored groups are disjoint, but the preprocessing refinement stopped when the PRIMARY splits were encoded-disjoint; it did not guarantee encoded closure for arbitrary later subdivisions. No main split regeneration is necessary. The first membership run stopped before shadow training and remains preserved as a failed preflight.

For the corrected run, compute connected components of stored group IDs and encoded-vector equivalence within each split. Exclude entire auxiliary components spanning old role buckets rather than moving any row to a different role. Persist exclusions and counts. Split the previously unused bucket7 by the resulting components. Use those components for bootstrap uncertainty. Preserve F/all-R cohorts; rebuild the independent retained control by excluding all components touching F, then apply the same label/family matcher. Freeze that rebuilt cohort across all models and report how many old retained-control rows shared an F component. This amendment uses metadata only, before improved attack fitting or evaluation, and corrects a detected leakage hazard rather than optimizing outcomes.

Keep all models, learned features, memberships, directions, quantiles and bootstrap settings fixed.
